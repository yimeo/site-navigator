# 功能验证记录

本记录对应当前交付版本的本地验证。测试使用临时 PHP 开发服务和 SQLite 数据库；运行环境为 PHP 8.3，仅用于验证 PHP 7.0 兼容写法和系统行为。生产部署仍应按 `README.md` 使用 NGINX 与 PHP 7.0-FPM。

| 验证项 | 方法 | 结果 |
| --- | --- | --- |
| PHP 源码语法 | 对 `app/`、`public/`、`cron/`、`tests/` 中所有 PHP 文件执行 `php -l` | 通过，无语法错误 |
| SQLite 初始化 | 执行 `tests/smoke.php` | 通过，自动创建管理员、默认分类及数据表 |
| URL 安全规则 | 冒烟测试传入公网 URL、本机 IP、非 HTTP 协议 | 通过，公网地址可规范化；本机地址与非 HTTP 协议被拒绝 |
| 公开导航页 | 打开首页 | 通过，显示搜索、三种排序入口、分类统计与空状态 |
| 后台登录 | 使用初始化管理员账户登录 | 通过，管理控制台、分类排序与网站列表正常显示 |
| 仅 URL 自动收录 | 输入 `https://example.com` | 通过，自动读取 `Example Domain` 标题和页面介绍，并进入确认表单 |
| 本地图标同步 | 对带图标站点执行 `tests/icon-integration.php` | 通过，图标下载为 `public/assets/icons/` 下的本地文件 |
| 主地址健康检测 | 执行 `php cron/check-sites.php --id=1` | 通过，保存 HTTP 200 与 `up` 状态 |
| 主备域名自动切换 | 将主地址模拟为无法解析地址、备用地址设为可用地址后访问跳转入口 | 通过，健康状态为主 `down`、备 `up`，跳转响应定位至备用地址 |
| 人气统计 | 访问统一跳转入口 | 通过，返回 302 并使 `websites.clicks` 累加 |
| NGINX 配置 | 临时加载 `deploy/nginx-site-navigator.conf` 后执行 `nginx -t` | 通过，配置语法有效 |

> 测试结束后已清理测试数据库记录和图标文件。实际部署时，数据库会在首次访问时重新初始化，管理员可从后台输入真实目标 URL 开始收录。
